# Plakoro Catalog

Каталог выпусков Plakoro и автоматический поиск кандидатов для проверки.

- `catalog/releases.json`: проверенные данные для календаря Godot.
- `sources/feeds.json`: список проверенных RSS/Atom-источников (пока пуст).
- `scripts/collect.py`: сборщик кандидатов.
- `.github/workflows/collect.yml`: ежедневный запуск и отчёт в GitHub Actions.

## Проверка
Сборщик не публикует найденное автоматически. Новые сведения необходимо сверять с первоисточником. Сначала добавьте проверенные HTTPS RSS/Atom-адреса в `sources/feeds.json`. Для сайтов без RSS потребуются отдельные адаптеры.

## Запуск
```bash
python scripts/collect.py
```

**Важно:** `owned.json`, `wishlist.json` и личные фотографии хранятся локально, их нельзя загружать в публичный репозиторий или перезаписывать обновлениями.

Статус: каркас инфраструктуры. Реальные источники и каталог релизов ещё не заполнены; интеграция с Godot ещё не выполнена.
